# Changelog

## 0.1.0 - 2026-10-05

- Add validated Gregorian civil dates and natural or fixed-six-week month models.
- Compile A4, A5, Letter, Legal, and custom paper sizes into measured page regions.
- Add configurable margins, orientation, weekday headings, cell gaps, notes, and footers.
- Add date-free blank planner grids.
- Add deterministic self-contained SVG and feature-gated JSON serialization.
- Add `papergrid month`, `papergrid blank`, and inclusive `papergrid range` commands.
